## 1. 基本文型

### 1.1 文体

#### 1.1.1 本文

本文の文体は**敬体（ですます調）**または**常体（である調）**のどちらかで統一する。混在させない。

**敬体（ですます調）**
- 一般読者向けの紹介文、パンフレット、マニュアル、ウェブサイトの本文で使用
- 親しみやすい、柔らかい雰囲気で内容を伝達

**常体（である調）**
- 簡潔に、力強い雰囲気で内容を伝達
- 丁寧ではない印象を読み手に与える場合があるため、一般向けマニュアルの本文では通常使わない

#### 1.1.2 見出し

- 本文が敬体でも、見出しには常体や体言止めを使用
- 「〜には」「〜とは」などの助詞で止める文形も使用
- 見出しの文末には句点（。）を付けない
- すべての見出しを通して複数の文体をできるだけ混在させない

**見出しの例**
- 用字と用語の使い方 → 体言止め
- タイマー予約する → 常体
- 困ったときには → 「〜には」助詞で止める形
- 環境に配慮するとは → 「〜とは」助詞で止める形

#### 1.1.3 箇条書き

- 基本的に本文の文体に合わせる
- 本文が敬体の場合、箇条書きに常体または体言止めも使用可
- 本文が常体の場合、箇条書きには常体または体言止めを使用（敬体は使わない）
- ひとまとまりの箇条書きでは、敬体と常体を混在させない
- 文末に句点（。）を付けるかどうかも統一

**例1（本文：敬体、箇条書き：体言止め）**
```
次をお知らせください。
・商品名と型名
・購入年月日
```

**例2（本文：敬体、箇条書き：常体）**
```
次の順序で操作してください。
・Shiftキーを押しながらEnterキーを押す。
・「いいえ」ボタンをクリックする。
```

#### 1.1.4 図表内のテキスト

- 文章の内容に応じて敬体・常体・体言止めを使用
- 敬体と常体を混在させない
- 通常、文末に句点（。）を付けない
- 複数の文章になる場合は句点を使用

#### 1.1.5 図表のキャプション

- 文章の内容に応じて敬体・常体・体言止めを使用
- 複数の文体をできるだけ混在させない
- 通常、文末に句点（。）を付けない
- 複数の文章になる場合は句点を使用

### 1.2 句読点の使用

#### 1.2.1 句点（。）と読点（、）

句読点には全角の「、」と「。」を使用する。和文の句読点としてピリオド（.）とカンマ（,）を使用しない。

| 正 | 誤 |
|---|---|
| これは、見本となる例です。 | これは，見本となる例です． |

#### 1.2.2 ピリオド（.）とカンマ（,）

欧文で表記する組織名などの固有名詞や数字にピリオド（.）やカンマ（,）が含まれる場合は、和文中でもピリオド（.）とカンマ（,）を使用する。いずれも**半角**で表記。

| 正 | 誤 |
|---|---|
| The Ministry of Economy, Trade and Industry | The Ministry of Economy，Trade and Industry |
| 785,105 | 785，105 |
| 12.5 | 12．5 |

## 2. 文字の表記

### 2.1 用字・用語

#### 2.1.1 ひらがな

- **全角**で表記
- 昭和61年7月1日内閣告示第1号「現代仮名遣い」に準拠

#### 2.1.2 漢字

- **全角**で表記
- 平成22年11月30日内閣告示第2号「常用漢字表」に原則として準拠
- 常用漢字表にない漢字でも、実務翻訳で慣用的に用いられる語には漢字を使用

**常用漢字表にないが使用する例**

| 使用する | 理由 |
|----------|------|
| 聡明、推敲、莫大 | 一般的に用いられている |
| 拿捕、改竄、楕円 | ひらがなと混ぜ書きすると不自然（だ捕、改ざん、だ円） |
| 罫線、右揃え | 漢字で書く方がわかりやすい |
| 梱包、斡旋 | 専門用語として定着している |

#### 2.1.3 漢字の送りがな

**動詞の送りがな**
- 内閣告示「送り仮名の付け方」の「本則」と「例外」に従う
- 「許容」として挙げられている送りがなは原則として使用しない

| 正 | 誤 |
|---|---|
| 行う | 行なう |
| 表す | 表わす |
| 現れる | 現われる |
| 浮かぶ | 浮ぶ |
| 終わる | 終る |

**名詞の送りがな**
- 「本則」と「例外」に従う
- 「許容」として挙げられている送りがなも使用する（送りがなを省略した表記が定着しているため）

| 使用する | 例 |
|----------|---|
| 答え、答 | 問いと答え。答の欄。 |
| 曇り、曇 | 晴れのち曇り。天気は曇です。 |
| 届け、届 | 届けを出す。転出届。 |
| 願い、願 | 願いを聞く。休暇願。 |

#### 2.1.4 複合語の送りがな

**活用のある複合語（動詞）では送りがなを省略しない**

| 正 | 誤 |
|---|---|
| 書き込む | 書込む |
| 取り扱う | 取扱う |
| 引き換える | 引換える |
| 申し込む | 申込む |
| 請け負う | 請負う |
| 組み立てる | 組立てる |

**動詞から派生した名詞では送りがなを省略できる**

| 使用可 |
|--------|
| 取り扱い、取扱い、取扱 |
| 繰り上げ、繰上げ、繰上 |
| 引き換え、引換え、引換 |
| 組み立て、組立て、組立 |
| 申し込み、申込み、申込 |
| 置き場、置場 |

**送りがなの省略が慣用として定着している名詞**

| 正 | 誤 |
|---|---|
| 取締役 | 取り締まり役（役職名） |
| 請負 | 請け負い（経済用語） |
| 繰入率 | 繰り入れ率（経済用語） |
| 申込書 | 申し込み書 |
| 売上金 | 売り上げ金 |

#### 2.1.5 カタカナ

- **全角**で表記
- 半角カタカナは特殊な用途を除いて原則として使わない
- 平成3年6月28日内閣告示第2号「外来語の表記」に従う

| モーター | モータ |
| カレンダー | カレンダ |
| レーダー | レーダ |
| モジュラー | モジュラ |
| アクセサリー | アクセサリ |
| エネルギー | エネルギ |
| アイデンティティー | アイデンティティ |

#### 2.1.7 カタカナ複合語

中黒または半角スペースを用いてカタカナ語を区切って表記する。

| 正 | 誤 |
|---|---|
| カー・ナビゲーション・システム | カーナビゲーションシステム |
| カー ナビゲーション システム | |

**区切り方法の特徴**

| 方法 | 特徴 |
|------|------|
| 中黒（・） | 語の区切りが明白、縦書きでも使用可、新聞・書籍で広く使用 |
| 半角スペース | 語の区切りが明白、見た目がすっきり、IT分野のマニュアルで主に使用 |
| 区切りなし | 語の区切りが不明瞭、機械翻訳時に未知語を判定しづらい |

**区切りを入れないカタカナ複合語の例**
ログイン、チェックアウト、リアルタイム、ダブルクリック、スタイルガイド、スピードアップ、バーコード

#### 2.1.8 算用数字

- **半角**で表記
- 用途によっては全角を許容するが、特別な理由がない限り半角を原則

#### 2.1.9 アルファベット

- **半角**で表記
- 用途によっては全角を許容するが、特別な理由がない限り半角を原則

#### 2.1.10 算用数字の位取りの表記

- 桁区切りには**カンマ**（省略する場合あり）
- 小数点には**ピリオド**

### 2.3 文字間のスペース

#### 2.3.1 単一文字間のスペースの有無

##### 全角文字と半角文字の間

原則として、全角文字と半角文字の間にスペースを入れない。

| 正 | 誤 |
|---|---|
| JTF標準 | JTF 標準 |

##### 全角文字どうし

原則として、全角文字どうしの間にスペースを入れない。

##### 半角文字どうし

和文中に欧文を引用するなど和文に欧文が含まれる場合は、欧文中の半角文字の間のスペースを維持。

#### 2.3.2 かっこ類と隣接する文字の間のスペースの有無

かっこの外側、内側ともにスペースを入れない。

## 3. 記号の表記と用途

### 3.1 句読点

#### 3.1.1 句点（。）

| 記号 | 表記 | 例 |
|------|------|---|
| 句点（。） | 全角 | A氏は「5月に新製品を発売します」と述べました。<br>従業員は約30,000人です（関連企業を含みます）。 |

- 文の終わりに付ける
- 文中にかぎかっこが入る場合、閉じかっこの前に句点を打たない
- 文中に丸かっこが入る場合も閉じかっこの前に句点を打たない

#### 3.1.2 読点（、）

| 記号 | 表記 | 例 |
|------|------|---|
| 読点（、） | 全角 | A社は、設備投資を続けながら業績が低迷する子会社を合併しました。<br>開発、営業、製造の3部門に通達しました。 |

- 文章の切れ目や語句の係り受けをはっきりさせる
- 文章を読みやすくしたり、意味を正しく伝えるために使用
- 並列する語句を並べるときにも使用

#### 3.1.3 ピリオド（.）、カンマ（,）

| 記号 | 表記 | 用途 |
|------|------|------|
| ピリオド（.） | 半角 | 桁区切り、小数点、箇条書きの数字 |
| カンマ（,） | 半角 | 桁区切り |

和文の句読点としては使用しない。

### 3.2 記号

#### 3.2.1 感嘆符（！）

| 記号 | 表記 |
|------|------|
| 感嘆符（！） | 全角 |

- 和文の実務文章の場合、本文では多用しない
- 原文で感嘆符が使われている場合も、和文ではできるだけ句点を使用

**感嘆符を使用する例**
- 警告！
- 驚きの速さ！ これが新製品のキャッチコピーでした。
- おおっ！という声が上がりました。

**ルール**: 文末に感嘆符を使用し、後に別の文が続く場合は、直後に**全角スペース**を挿入。文中に使用する場合はスペースを挿入しない。

#### 3.2.2 疑問符（？）

| 記号 | 表記 |
|------|------|
| 疑問符（？） | 全角 |

- 和文の実務文章の場合、本文では多用しない
- 原文で疑問符が使われている場合も、和文ではできるだけ句点を使用

**疑問符を使用する例**
- オプションを変更しますか？
- A社の成功の秘密とは？ この本ではそれをご紹介します。
- どう操作したらよいのか？というユーザーの疑問に答えます。

**ルール**: 文末に疑問符を使用し、後に別の文が続く場合は、直後に**全角スペース**を挿入。文中に使用する場合はスペースを挿入しない。

#### 3.2.3 スラッシュ（/）（／）

| 記号 | 表記 | 例 |
|------|------|---|
| スラッシュ | 半角または全角 | 1/3（分数）、I/O、50Hz/60Hz、オン／オフ |

- 分数を表す場合、欧文の語句で使用されている場合、「または」の意味で語句を並べる場合に使用
- 和文では多用しない

#### 3.2.4 中黒（・）

| 記号 | 表記 | 例 |
|------|------|---|
| 中黒（・） | 全角 | 小・中学校、パーソナル・コンピューター |

- カタカナ複合語を区切る場合、同格の語句を並列する場合に使用
- カタカナ複合語の区切りと同格の語句の並列に同時に中黒を使用するのは推奨しない（読み手の理解を妨げる場合があるため）

#### 3.2.5 波線（〜）

| 記号 | 表記 | 例 |
|------|------|---|
| 波線（〜） | 全角 | 18〜22歳 |

#### 3.2.6 ハイフン（-）

- 原則として和文では使用しない

#### 3.2.7 コロン（：）

## 4. 単位の表記

### 4.1 単位系

- JIS規格Z8000-1〜Z8000-12「量及び単位」に従う
- 英字で表記する単位記号は、大文字と小文字の使い方も含めて、国際単位系（SI）で定められた英字を使用
- 該当するSI単位がない「dpi」や「カロリー」などの単位も必要に応じて使用

### 4.2 単位記号の表記

主に以下の2種類の表記方法がある：
- 英字による表記：kg、mm、MB、W、Hz
- カタカナによる表記：キログラム、ミリメートル、メガバイト、ワット、ヘルツ

「時間」の単位は、「時」「分」「秒」などの漢字を使って表記。

### 4.3 個別の単位

| 分類 | 使用する単位 |
|------|-------------|
| 時間・時刻 | 時間、時、分、秒、ミリ秒 |
| 長さ | mm、km、ミリメートル、センチメートル |
| 質量 | g、kg、t、グラム、キログラム、トン |
| 面積・体積 | ㎡、平方メートル、立方メートル |
| 電気 | A、W、V、アンペア、ワット、ボルト |
| 温度 | ℃、度 |
| 周波数 | Hz、ヘルツ |
| 速度 | m/s、キロメートル毎時、分速〜km |
| 伝送速度 | bps、Kbps、バイト/秒 |
| 割合 | ％、パーセント |
| 角度 | 90°、90度 |
| 記憶容量 | ビット、バイト、Kb、KB、Mb、MB |
| 通貨 | 円、米ドル、ユーロ、＄、USD |
